# data/

This folder is intentionally empty in the repository.

The MovieLens 1M files (`ratings.dat`, `movies.dat`, `users.dat`) are **not** committed:
the GroupLens terms of use do not allow redistribution. Download them yourself:

    https://grouplens.org/datasets/movielens/1m/

Unzip so the files sit in `data/ml-1m/`, or let the notebook download them (see the first
data-loading cell of the notebook).
